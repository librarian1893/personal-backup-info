Privacy Policy

Last updated: October 10, 2026

1. Purpose

This privately operated utility creates and maintains backups of data managed by its operator.

2. Data Access and Use

The utility uses the Google Drive API to access the operator's Google Drive account for backup operations. Depending on the granted permissions and configured settings, it may list, upload, manage, and delete backup files.

Google user data is used only as needed to provide the configured backup and retention functionality. The permissions granted to the application may allow broader access than the files used during normal backup operations.

3. Storage and Security

Backup archives are password-protected before upload. OAuth credentials and related configuration are stored on the operator's server. The operator is responsible for protecting access credentials and backup passwords.

4. Sharing

This utility does not sell Google user data or use it for advertising. Data is handled only as needed to operate the configured backup service, provide cloud storage functionality, or comply with applicable law.

5. Retention and Deletion

Backup files are retained according to the operator's configured retention settings and may be deleted automatically or manually.

6. Revoking Access

The operator can revoke the utility's Google account access through their Google Account security settings.

7. Contact

For privacy-related questions, use the developer contact information provided in the associated application settings.
